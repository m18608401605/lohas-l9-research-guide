# 乐活元 L9 小组研究指南

BUSI2178 营销管理报告的写作前研究指南。网页按研究问题说明需要查找的关键证据、一般证据和替代证据，以及各类资料能支持的结论与推论边界。

## 使用

打开网站，先阅读作业共识，再从 11 张研究问题卡片中选择任务。检索词可复制，资料入口可直接打开。找到资料后，按网页中的统一格式保存原始链接、日期、地域、型号、指标口径、支持的命题和反证。

网页是静态指南。勾选状态不会同步，组员请在现有共享文档中记录证据与讨论结论。

## 资料边界

本项目是研究辅助材料，不替代课程正式作业文件。企业网页用于说明企业自身表述；独立研究与统计数据也需检查地域、时期、产品范围和指标口径。页面标注的资料缺口仍需小组核查。

## 发布

网页由仓库根目录的 `index.html`、`styles.css`、`data.js` 和 `app.js` 构成，无需构建。GitHub Pages 可选择 `main` 分支的仓库根目录作为发布源。
