# 乐活元 L9 小组研究指南

BUSI2178 营销管理报告的写作前阅读指南。网页将课程任务转成“研究问题 → 对应资料 → 允许的推论 → 推论边界 → 管理决策”的证据矩阵。

## 使用

网站分为“作业目标”“研究问题”“资料怎么用”“讨论与判断”四个主页面。先理解作业，再浏览 6 个优先问题；另外 2 个问题按讨论需要补看。点击五列表中的任意一行进入详情页，了解为什么查、优先找什么、知识点怎样解释资料、找不到关键证据时如何替代，以及资料能支持怎样的决策。

网页是静态说明书，没有需要填写或提交的表格。小组自行讨论资料和报告判断，网站不预设结论。

## 资料边界

本项目是研究辅助材料，不替代课程正式作业文件。企业网页用于说明企业自身表述；独立研究与统计数据也需检查地域、时期、产品范围和指标口径。页面标注的资料缺口仍需小组核查。

## 发布

网页由仓库根目录的 `index.html`、`tasks.html`、`task.html`、`sources.html`、`decision.html`、`styles.css`、`matrix.css`、`multi.css`、`data.js`、`round-one.js` 和 `app.js` 构成，无需构建。GitHub Pages 使用 `main` 分支的仓库根目录作为发布源。
