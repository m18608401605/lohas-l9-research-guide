# 乐活元 L9 小组研究指南

BUSI2178 营销管理报告的写作前研究指南。网页将课程任务转成“第一轮资料 → 允许的推论 → 推论边界 → 管理决策”的证据矩阵。

## 使用

打开网站，先看作业目标，再从 6 项 P0 任务中分工；另外 2 项 P1 按发现的问题补查。点击矩阵中的任意一行，可查看关键证据、一般证据、替代触发条件、来源入口、检索词及交付物。找到资料后，按统一格式保存原始链接、日期、地域、型号、指标口径、允许推论、反证和决策影响。

网页是静态指南。勾选状态不会同步，组员请在现有共享文档中记录证据与讨论结论。

## 资料边界

本项目是研究辅助材料，不替代课程正式作业文件。企业网页用于说明企业自身表述；独立研究与统计数据也需检查地域、时期、产品范围和指标口径。页面标注的资料缺口仍需小组核查。

## 发布

网页由仓库根目录的 `index.html`、`styles.css`、`matrix.css`、`data.js`、`round-one.js` 和 `app.js` 构成，无需构建。GitHub Pages 使用 `main` 分支的仓库根目录作为发布源。
